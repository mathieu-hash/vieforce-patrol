SAP vs Patrol: “Reports to (U_RSM)” comes from Business One — that is your SAP sales hierarchy. Patrol uses separate fields on each Supabase user: Region, District, and Territory (set on Sales Admin — main user table, Edit user). Who belongs to whom in Patrol: Region → RSM-style scope. District → DSM + every TSR/Champion in that district must use the same District text. Territory → optional label (e.g. route); does not replace District.
