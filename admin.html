Who belongs to what (fill this carefully)

Patrol uses the fields Region, District, and Territory on each user to decide dashboards, maps, and team lists. Maintain the master list on Region / District / Territory (SAP sync for regions & districts), then pick from the dropdowns below.

Region (RSM scope) → District (DSM + TSR team) → Territory (optional sub-area / route label)
  • TSR / Champion — Set Region and District to the district team they belong to. Must match their DSM’s District exactly. Territory is optional (e.g. route name).
  • DSM — Set Region + District for the district they manage. If the DSM person is replaced, edit this user row (or add the new DSM with the same District); keep TSR District values unchanged.
  • RSM / CEO — Set Region for rollups and maps. District is usually blank unless you need a sub-scope.
  • Stores / farms — Assignment to a TSR is separate (assigned_tsr in the database). User fields above define which DSM sees which people; POS assignment is done per store/farm.
